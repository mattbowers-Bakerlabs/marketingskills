# BML Local-Service Fit

A fit lens over the 139 ideas in [ideas-by-category.md](ideas-by-category.md) for Baker Labs (BML) clients: home services and construction, clinical practices, multi-location brands, professional services. It does not change the library. **Idea numbers 1–139 are shared with `marketing-plan` and must never be renumbered.** BML's own plays use `BML-<n>` IDs (appendix below) so they can't be confused with upstream numbers or with question-bank rows like B-1.

## Tags

| Tag | Meaning for a BML client |
|---|---|
| `Fit` | Works as written |
| `Adapt` | Works only in the local version in the Note column. Recommend the local version, not the upstream wording |
| `Rare` | Possible, but only with a specific reason in the client's rows (named in the shortlist). Never a default pick |
| `SaaS-only` | Assumes software, signups, trials, apps or investors. Skip unless page 13 shows a software product |
| `Skip` | Not recommended for BML clients for another reason (Note says why) |

## Gates

Check every gate before an idea goes on the shortlist. A gate that fails moves the idea to "Not recommended" with the row named.

| Gate | Check |
|---|---|
| `C` | Clinical clients: context-rules §7. No scarcity, urgency, fear, stunt or outcome-promise framing unless a page 12 row permits it; no pixels or forms on patient-facing pages without a person's compliance sign-off; no patient data |
| `J-3` | Regulated incentives or licensing. Paying referrers is restricted in some segments (clinical, real estate, some trades). Needs J-3 answered, and a person to confirm |
| `J-4` | Names or targets competitors. Blocked if J-4 forbids it |
| `J-6` | Uses photos, video or likenesses. Needs releases on file (J-6; G-5 for patients and testimonials) |
| `$` | Needs paid spend. Must fit B-10; if B-10 is `OPEN`, write `[NEEDS PROOF: B-10]` and propose no amount |
| `B-6` | Adds volume. Check capacity and seasonality (B-6, I-10) first |
